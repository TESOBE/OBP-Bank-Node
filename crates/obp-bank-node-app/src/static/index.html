OBP Bank Node — Open Corridor

1 Send

POST an OPEN_CORRIDOR A1.1 request to a node's south-side API.


      

    


    

      
2 Promise

      
Each node's outbox: INITIATED → SUBMITTED → PROMISE_WRITTEN → REPORTED.
        The on-chain promise is a salted SHA-256 commitment — hash only; cleartext and salt stay with the banks.

      

    


    

      
3 Position

      
This bank's unsettled outbound exposure per corridor
        (SUBMITTED/PROMISE_WRITTEN/REPORTED, not yet covered by a settlement).
        A node only knows its own outbound legs — the authoritative bilateral net is computed by
        OBP-API at settle time (see the corridor view in step 4).

      

    


    

      
4 Settle

      
Ask a node to trigger bilateral settlement: it calls OBP-API's settlement resource over
        Interface B; the net moves later on the rail (SETTLING → SUBMITTED → FINAL).

      

        

          
          
          
        

        
        

      

      

      

    


    

      
5 Credit

      
Beneficiary-side evidence: the commit–reveal triplet, whether
        SHA-256(salt ‖ preimage) matched the on-chain commitment, and the CBS delivery result.

      

    

  


  

    
Read-and-trigger only; outside the money path. Every state shown is read from a node endpoint.
